# R14 outcome and authorization boundaries

Consumer UI -> local HTTP bridge -> actual Streamable HTTP MCP client -> mission/plan authority -> fenced owned executor -> real media HTTP/Chrome. A separate fresh subprocess observes full media bytes, pinned native video, Chrome compositor and independent decoder source reference over a temporal window.

Executor acceptance is never completion. Stable logical target and immutable goal/content remain separate from per-attempt ephemeral browser/runtime binding. Runtime reassociation is allowed after an owned document loader change or owned restart; same-document DOM replacement cannot retarget the observed element.

The durable target context holds latest goal revision, active mission, revocation and independently observed bookmark. New goals and Cancel persist revocation before waiting for serialized native effects. Positive effects check current authority again. Native boundary callbacks only pause and are invalidated by later execution nonces. MCP networking does not hold a global request lock, so Stop can reach authority during a probe.

Preview/confirmation/revoke are MCP-authoritative, concrete, expiring and one-use. A viewing promise records its start/end, maximum repairs, durable consumed allowance and monitoring deadline. Reservation/allowance precede effects. Stage playback can be verified while the whole plan is active; terminal success requires correct content and actual stopped endpoint. New authority is needed after revocation or expired monitoring.

All receipt reads are historical. Fresh read/probe is required for current truth. A source hash checks bytes, not human perception, receipt authenticity or general semantic video recognition. A thumbnail is observed compositor evidence with a bounded lifetime, not an outcome oracle. State JSON stores configuration and evidence; assigning success fields cannot make playback true.

Trusted boundary: local OS, Chrome/CDP and packaged verifier code. DOM/CSS/getter manipulation is tested; arbitrary hostile OS/browser attestation is not claimed. Legacy production execution remains unavailable. No production Runtime/controller is modified.
